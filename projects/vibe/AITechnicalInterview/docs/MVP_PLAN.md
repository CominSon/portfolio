# План развития MVP

## Фаза 1 — Основа (сделано в каркасе)
- [x] Структура monorepo: `backend/`, `frontend/`, `docs/`
- [x] Схема PostgreSQL (SQLAlchemy + `docs/SCHEMA.sql`)
- [x] Модульные сервисы FastAPI
- [x] React Admin + Interview Room
- [x] Контракты WebSocket + REST
- [x] Docker Compose для локального запуска

## Фаза 2 — Основной сценарий интервью
- [ ] E2E: работодатель создаёт сессию → кандидат заходит → media gate → старт
- [ ] Устойчивый STT по кнопке «Ответить»
- [ ] Первое сообщение AI без дублирования REST + WebSocket
- [ ] Автовыбор формата по подтверждённым компетенциям

## Фаза 3 — Совместное редактирование
- [ ] Debounce локальных правок → `code_insert` по WS
- [ ] Действия AI в Monaco (подсветка, комментарии)
- [ ] Снимки кода при submit + автосохранение
- [ ] API replay timeline для работодателя

## Фаза 4 — Запись и отчёт
- [ ] Склейка чанков записи (ffmpeg)
- [ ] `offset_ms` в транскрипте
- [ ] Экспорт отчёта в PDF
- [ ] Просмотр отчёта в Admin

## Фаза 5 — Шаблоны
- [ ] CRUD шаблонов в Admin UI
- [ ] Сценарий «только резюме» из шаблона
- [ ] Мастер настройки шаблона с AI

## Фаза 6 — Продакшен
- [ ] Авторизация (JWT)
- [ ] Rate limit на STT/TTS
- [ ] Интеграционные тесты
- [ ] Деплой на VPS — см. `docs/DEPLOYMENT.md`
