# Что я умею — справочник для чата

## Как этим пользоваться

**Файл вы сами открывать не обязаны.** Просто напишите в чате GigaCode одну из фраз:

- **«Что ты умеешь?»**
- **«Покажи все MCP функции»**
- **«Справочник MCP»**
- **«Какие команды доступны?»**

Агент прочитает этот файл и выведет список **обычными словами** — прямо в чате.

Готовые промпты для **Prompt Library** в GigaCode: `GIGACODE_PROMPT_LIBRARY.md`.

Если нужны технические детали (служебные функции, которые агент вызывает сам) — напишите:
**«Покажи все функции с доп.»** или **«Справочник MCP полный»**.

### Загрузка файла в Greenplum — как это работает

Вы пишете, например: **«Загрузи мне Z:\LABA_LOAD\данные.csv»**

Агент спросит только:

1. **В какую таблицу загрузить?** — полное имя, например `s_grnplm_ld_blago_ubhq_work.my_table`
2. Для **Excel** (.xlsx / .xls) — **имя листа**

**Кодировку и разделитель CSV агент определяет сам** (как вы уже проверяли). Спрашивать вас не обязан.

После ответа агент загрузит файл: создаст таблицу, если её нет, очистит и зальёт данные.

> **Ошибки SQL:** если запрос не выполнился, агент **сам исправит и повторит** (до 3 попыток). Вам не нужно просить «попробуй ещё раз» — достаточно дождаться результата или уточнить задачу.

> Выгрузки сохраняются в папку **`export`** внутри открытого проекта в IDEA.  
> **Git и выгрузки используют один и тот же проект** — достаточно один раз сказать «работаем с U:\BDProjects\users_scripts».

## Служебные функции (доп.) — агент вызывает сам

Показывать **только** если пользователь просит «с доп.» / «полный справочник» / «технические функции».

### Greenplum

| Функция | Когда вызывается автоматически |
|---------|-------------------------------|
| `healthcheck` | При первом обращении к БД |
| `set_project_path` | Один раз при смене проекта в IDEA (общий для GP и Git) |
| `get_project_path` | Для проверки пути выгрузок |
| `use_mcp_cwd_as_project` | Попытка взять папку из IDEA при старте |

### Bitbucket

| Функция | Когда вызывается автоматически |
|---------|-------------------------------|
| `healthcheck_git` | При первой git-операции |
| `set_project_path` | Только при смене репозитория; иначе берёт общий путь из Greenplum |
| `get_project_path` | Перед git-операциями для проверки |
| `git_commit` / `git_push` | Отдельно, если явно попросили «без push» |
| `update_mcp_servers` | По фразе «Обнови мои MCP Серверы» — sync из python.git master |

### Почта

| Функция | Когда вызывается автоматически |
|---------|-------------------------------|
| `healthcheck_mail` | При первой работе с почтой |
| `get_mail_profile` | Перед отправкой, чтобы подставить ваш email в `to` |
| `resolve_recipients` | При отправке по ФИО |
| `dry_run` в `send_email` | По желанию — показать получателей без отправки |
