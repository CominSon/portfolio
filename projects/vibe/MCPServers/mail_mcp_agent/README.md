# Mail MCP — краткая инструкция

Корпоративная почта omega (POP3/SMTP), как в Outlook.

## Первый запуск

1. Вызовите **`healthcheck_mail`** — автоматически настроит логин, пароль (noterball), email.
2. Дальше можно искать и отправлять письма.

## Основные команды

| Задача | Что вызвать |
|--------|-------------|
| Найти письмо | `search_messages` → `get_message` |
| Последние письма | `list_messages` |
| Найти email по ФИО | `resolve_recipients` |
| Отправить письмо | `send_email` с явным `to: ["email@..."]` |
| Проверить свой email | `get_mail_profile` |

## Отправка письма

- **Всегда** указывайте `to` с реальными адресами — они видны в окне подтверждения RUN.
- `dry_run: true` — показать получателей без отправки.
- `send_to_self: true` — дополнительно добавит ваш email.

## Чтение писем

- `get_message` показывает текст (включая HTML), вложения и **приглашения на встречи** (`.ics`).
- POP3 — только папка INBOX.
