Настройки MCP для GigaIDE (Tools → GigaCode → MCP).

Каждый сервер добавляется ОТДЕЛЬНО: свой блок JSON (или строка Configuration).
Общее для всех:
  PYTHONPATH = U:\MCP Servers;U:\Python313\site-packages
  PYTHONUNBUFFERED = 1
  cwd = U:\MCP Servers

После настройки: перезапустите MCP Server и начните новый чат.

================================================================================
1) greenplum
   Configuration: python -u -m gp_mcp_agent
================================================================================
{
  "mcpServers": {
    "greenplum": {
      "command": "python",
      "args": ["-u", "-m", "gp_mcp_agent"],
      "env": {
        "PYTHONPATH": "U:\\MCP Servers;U:\\Python313\\site-packages",
        "PYTHONUNBUFFERED": "1"
      },
      "cwd": "U:\\MCP Servers"
    }
  }
}
