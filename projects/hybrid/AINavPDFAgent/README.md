# AINavPDFAgent

**AINavPDFAgent** — интеллектуальный AI-агент для формирование умных pdf-выгрузок с шаблонами, корректировками, разовыми выгрузками. 

---

## Технологический стек

- **Python 3.12**
- **Gigachat Max** — LLM и эмбендинги (официальный API)
- **PostgreSQL 17.5** — хранение истории, активных задач, шаблонов
- **pytest** — тестирование, покрытие кода (возможно)
- **black, isort, mypy, ruff** — автопроверка и форматирование кода (возможно)

---

## Структура репозитория (короткая)

- **src/** — исходный код приложения:
    - **main.py** — точка входа, запуск сервиса
    - **modules/** — ключевые модули:
        - **common/** — Универсальные модули, используемые в нескольких модулях
        - **core/** — Модуль оркестрации направленный на управление свободными профилями
        - **db/** — работа с PostgreSQL
        - **gigachat/** — интеграция с Gigachat Max
        - **llm/** — обработка промптов, логика RAG, генерация/дробление запросов
        - **mail/** — модуль работы через smtp
        - **pdf/** — модуль подготовки pdf-скринов
    - **resources/** — настройки, индексы, промпты
    - **logs/** — файлы логов

- **test/** — модульные и интеграционные тесты (используйте pytest)
- **docs/** — документация, архитектура, API, ER-диаграммы
- **.env** — пример файла окружения (секреты НЕ храним в git)
- **requirements.txt** — зависимости для быстрого развертывания (пока не актуально)

## Кратко о проекте

AINavPDFAgent - агент направлен на работу с выгрузками PDF. Агент через естественный запрос понимает какую выгрузку сделать, используя предварительные шаблоны и описание.

---

> Все секретные ключи, токены и пароли хранить только в локальных файлах `.env` или `resources/secrets/` и не коммитить в git!

## Текущая функциональность агента
1) Функциональность формирования PDF по предоставленным ссылкам:
    - Сотрудник пишет на почтовый адрес `info_shtab_ub@sberbank.ru` запрос с просьбой сделать PDF по ссылке или нескольким ссылкам;
    - Агент анализирует сообщение и формирует задачу на формирование PDF;
    - Сформированный PDF отправляет заказчику;
2) Мониторинг активных и отработанных задач через БД;
3) Отработка задач в параллельном режиме

## Функциональность на доработку

1) Функциональность через кнопку в Навигаторе (разовые выгрузки):
   - Сотрудник выставляет фильтры и нажимает кнопку выгрузить PDF; 
   - ссылка (или несколько ссылок) направляется в Агента (через Outlook) и Агент запускает PDF-скан; 
   - результат направляет обратно по почте;
2) Шаблонные выгрузки по запросу:
   - Сотрудник пишет агенту (через Outlook) - "Хочу сформировать шаблон";
   - Агент предлагает заполнить форму шаблона (в шаблоне будет название отчета (или группа отчетов - "Например: ОС УБ"), ссылки на страницы, короткое описание страниц (например - вкладка Свод раздела Protection показывает  все основные показатели направления);
   - Шаблон отправляется обратно агенту (через Outlook);
   - Агент обрабатывает Шаблон и добавляет в базу отчетов (Сотруднику отправлено сообщение, что  шаблон добавлен);
   - Далее сотрудник в любой момент:
     - может написать агенту - "сделай мне PDF всей ОС УБ" = агент делает PDF по всем страницам ОС УБ;
     - может написать агенту - "сделай мне PDF ОС УБ только вкладок "СВОД" по каждому направлению" = агент делает PDF только по нужным ссылкам, исходя из описания
     - может написать агенту - "Присылай мне PDF всех страниц ОС УБ каждый день в 14 00" = агент ставит на расписание PDF и направляет строго по времени.
