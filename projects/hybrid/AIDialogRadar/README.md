# AIDialogRadar

**AIDialogRadar** — интеллектуальный AI-бот для корпоративного поиска и извлечения знаний из истории переписок СберЧата, построенный на технологиях RAG и LLM (Gigachat Max). Проект создан с прицелом на высокую надежность, качество кода и масштабируемость.

---

## Технологический стек

- **Python 3.12**
- **Gigachat Max** — LLM и эмбендинги (официальный API)
- **RAG (Retrieval Augmented Generation)** — архитектура для интеллектуального поиска
- **СберЧат** — интеграция через официальный Python SDK, тестовый стенд: sandbox
- **PostgreSQL 17.5** — хранение истории, пар вопросов-ответов и пользовательских оценок
- **Flask** — легковесный веб-интерфейс (API-панель поиска)
- **pytest** — тестирование, покрытие кода (возможно)
- **black, isort, mypy, ruff** — автопроверка и форматирование кода (возможно)

---

## Структура репозитория (короткая)

- **src/** — исходный код приложения:
    - **main.py** — точка входа, запуск сервиса
    - **modules/** — ключевые модули:
        - **common/** — Универсальные модули, используемые в нескольких модулях
        - **core/** — Оркестрация при работе всего скрипта
        - **db/** — работа с PostgreSQL
        - **gigachat/** — интеграция с Gigachat Max
        - **llm/** — обработка промптов, логика RAG, генерация/дробление запросов
        - **sberchat/** — работа с СберЧат SDK
        - **web/** — Flask-приложение, обработка API-запросов
    - **resources/** — настройки, сертификаты, индексы, промпты
    - **logs/** — файлы логов

- **test/** — модульные и интеграционные тесты (используйте pytest)
- **docs/** — документация, архитектура, API, ER-диаграммы
- **.env** — пример файла окружения (секреты НЕ храним в git)
- **requirements.txt** — зависимости для быстрого развертывания (пока не актуально)

## Кратко о проекте

AIDialogRadar автоматически анализирует пользовательские вопросы, осуществляет интеллектуальный поиск релевантной информации в чатах (в том числе с использованием дробления запросов и chunking), агрегирует ответы и запоминает удачные комбинации. Система самообучается на положительных пользовательских оценках.

---

> Все секретные ключи, токены и пароли хранить только в локальных файлах `.env` или `resources/secrets/` и не коммитить в git!
