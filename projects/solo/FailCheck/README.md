# Скрипт для отслеживания информации по переданным таблицам из СМД в ПКАП

### Источник - БД Oracle(TNS - PKAPUB_PROM.ca.sbrf.ru);

### Python 3.6.1 |Anaconda 4.4.0 (64-bit)

#### Для работы скрипта необходимо:

    1) Библиотеки из списка в requirements.txt;
    2) Пользовательские библиотеки - noterball, connectBD (запросить у автора);
    3) Доступ к ФИР (\\Admira203\Vol1);
    4) Установить сетевым диском (Z:\) \\Admira203\Vol1\DBS_BLAGO_FD;
    5) Установленный Firefox (текущая версия - 98.0);
    6) Стандартный набор библиотек Anaconda

#### Способ работы со скриптом: 
Автозапуск по времени (пн-пт в 9:00 и в 16:00)


#### Возможные проблемы:

1) Некорректная работа web-интерфейса 
https://iamproxy-ecmlite-prod.apps.prom-terra000029-ias.ocp.ca.sbrf.ru/ui/;
2) Один из файлов (Job_Error_PKAP.xlsx, Job_Error_last_PKAP.xlsx) занят пользователем;
3) cx_Oracle может не работать, если на ПК установлена 32-bit версия Oracle;
